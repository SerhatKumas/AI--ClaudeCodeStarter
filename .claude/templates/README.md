# Templates

Scaffolds the commands and skills reference so generated documents are consistent.

| Template | Used by |
|----------|---------|
| `pr-description.md` | `/ship`, `git-workflow` rule |
| `adr-template.md` | Architecture decisions (`rules/05-documentation.md`, `06-architecture.md`) |
| `issue-template.md` | Filing bugs/features |

Adapt the fields to your team. If you keep `.github/` templates, you can symlink or
mirror these so humans and Claude use the same format.
